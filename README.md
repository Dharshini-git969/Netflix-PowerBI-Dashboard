# Netflix-PowerBI-Dashboard
Interactive Power BI dashboard analyzing Netflix content through visual analytics, revealing trends in movies, TV shows, genres, ratings, countries, and release years for business insights.

# Netflix Data Visualization Dashboard | Power BI

## Project Overview

This project presents an interactive **Netflix Data Visualization Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes Netflix's extensive content library to uncover valuable business insights through interactive visualizations and data storytelling.

The project transforms raw Netflix data into meaningful dashboards that enable users to explore content trends, distribution patterns, audience classifications, and regional insights. It demonstrates practical applications of Business Intelligence (BI) tools for real-world data analysis and decision-making.


# Objectives

The primary objectives of this project are:

- Analyze Netflix's content library using interactive dashboards.
- Compare Movies and TV Shows available on Netflix.
- Explore country-wise content distribution.
- Identify popular genres and content categories.
- Analyze content ratings and audience classifications.
- Examine release trends across different years.
- Develop an interactive dashboard for efficient business analysis.

# Key Insights

- Netflix's content library has experienced significant growth over recent years.
- Movies represent a larger portion of the platform's content compared to TV Shows.
- Certain countries contribute a substantial share of Netflix's available titles.
- Drama, Comedy, and International content are among the most represented genres.
- The dashboard highlights audience preferences through content rating distributions.
- Interactive filtering enables users to explore insights efficiently from multiple perspectives.
